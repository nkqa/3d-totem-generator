这是什么网站？

这个网站用于生成您的皮肤在《我的世界》中的3D图腾

怎么使用该工具？

非常易于使用，只需要上传皮肤并下载它！

怎么获取玩家皮肤？

在“获取玩家皮肤”处选择 Java 版 或 基岩版，输入用户名后点击“获取皮肤”即可

1、Java 版填写的是玩家的 Java 版正版 ID

2、基岩版填写的是玩家的 Xbox 用户名（Gamertag），且该玩家需曾在基岩互通服务器出现，否则可能查询不到

3、获取到的皮肤仅支持 64×64 与 128×128 两种尺寸

为什么我无法上传或下载？

1、本站仅支持 64×64 与 128×128 大小的皮肤展开图

2、请使用 Chromium 内核的浏览器进行操作，例如 Google Chrome、Microsoft Edge、Kiwi Browser

其它功能请前往原作者的 GitHub 项目去反馈
